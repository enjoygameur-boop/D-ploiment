14. PIEGES DEJA PAYES
- Push-Location seul ne suffit pas a cmd : le repertoire courant de cmd n est pas celui de PowerShell. Utiliser cd /d.
- Les guillemets simples PowerShell n interpretent pas les sequences d echappement : les backticks partent en dur dans le C, erreur C2018 U+60. Utiliser des guillemets doubles.
- Un hash different ne prouve rien : le timestamp PE change a chaque link. Seul Contains prouve le contenu.
- Un exe plus recent que le HTML ne prouve pas que le HTML est dedans.
- RobRunPort.exe dans 1_run\payload survit aux rebuilds : sans comparaison fichier par fichier, l AIO embarque la veille.
- Remove-Item global sur %TEMP% ne descend pas dans les sous-dossiers.
- La politique d execution bloque kill.ps1 : passer par RunAs avec Bypass.
- Relancer l AIO sans purge reutilise l ancien payload et fait conclure sur du vide.
